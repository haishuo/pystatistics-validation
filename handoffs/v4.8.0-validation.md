  machine-precision. **coxph concordance now EXACT (1.1e-16)** — the Harrell tie fix closed
  the old ~1e-4 definitional gap (supersedes the `survival-validation-held-findings` note).
  Scaling O(n), py/R 0.7–1.1x (no complexity gap). Convergence 6/6 flag-match. R15 default

### timeseries — VA-4/VA-4b + A9 (BLESSABLE)
- **VA-4 xreg/drift/fixed** (`run_xreg.py`, 21/21): coef ~1e-5, loglik ~1e-9, AIC/sigma2
  machine-precision, SE ~4e-5, forecast pt ~1e-6 vs `stats::arima`+`predict.Arima`. R10 hard
  cases pass (xreg under d=1, near-collinear xreg, all-but-one fixed, drift under d=1,
  seasonal+xreg). Fail-loud 12/12 (xreg+Whittle, GPU backend, double-differencing,
  newxreg missing/misshape).
- **A9 closed**: the 4.8.0 report reflects the 4.6.12 arima GPU fail-loud fix (which made the
  4.6.6 report code-stale) + VA-4.
- Perf: py faster than R across acf/arima/ets/stl (0.14–0.40x). arima_batch Forge/CUDA rows
  **carried forward** from 4.6.6 (kernel `_arima_batch.py`/`_whittle.py` byte-unchanged;
  CPU batch contract reproduced live at 4.8.0). ndiffs(test='adf') nile boundary carries
  forward as the documented B-item (default test='kpss' matches R).
- **Finding TS-1** (documented benign behavior; NOT a defect): `auto_arima` on AirPassengers
  selects ARIMA(2,1,2)+drift at AICc 1355.17, **strictly lower** than `forecast::auto.arima`'s
  (4,1,2)+drift at 1357.22 — pystatistics' exact-ML optimizer reaches an optimum
  `forecast::Arima`/`stats::arima` miss (loglik −671.27 vs their −681.06). **Verified**: R
  evaluated at pystatistics' exact coefficients returns the identical loglik/sigma2; AICc
  machinery bit-identical on the matched (4,1,2) model; the (2,1,2) fit is causal+invertible.
  The estimator matches R for any fixed order — only the stepwise endpoint differs, and it is
  never worse on AICc. Harness pass-criterion corrected from strict order-equality to
  "py AICc ≤ R AICc" (order-equality wrongly scored a WIN as a fail; it only passed at 4.6.6
  because py couldn't fit drift and coincidentally matched the order with a worse model).
  Documented in meta + report.
