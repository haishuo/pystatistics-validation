## Tier C — rulings taken (sensible defaults, preliminary)

- **C1 — family-name strings:** break the emitted `.family_name` in 5.0 (folded
  into A9/A13). Not a dual-spelling forever.
- **C2 — `data` vs `X`:** keep `data` / `data_or_design` on mvnmle and mice. A
  full data matrix with missingness is semantically not a regression design
  matrix. Recorded as a **CONVENTIONS amendment candidate** (bless the split),
  NOT a rename. No 5.0 row.
- **C3 — `k` in gam** `s()/te()/ti()` (basis dimension): accept as a documented
  S1 exemption alongside `x`/`y`/`X` — deeply mgcv-canonical; a `basis_dim`
  rename would alienate every mgcv user for no semantic gain. No 5.0 row.
- **C4 — `ETSForecast`/`ARIMAForecast`:** leave as bare dataclasses (a distinct
  "forecast" object category, not a fit `…Solution`). No 5.0 row. Revisit only if
  a uniform forecast envelope is later wanted.
- **C5 — multinomial `.coefficient_matrix`:** keep the descriptive 2D name; add a
  `.coefficients` alias for the uniform surface (→ B7). Additive.
