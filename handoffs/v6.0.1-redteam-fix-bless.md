# v6.0.1 — red-team fix release, blessed

`pystatistics==6.0.1` (on PyPI 2026-07-24) fixes the **12 defects** the fresh 6.0.0
adversarial red-team found in `mvnmle` + `mice` (see
`mvnmle-mice-6.0.0-redteam-findings.md`). This is a pure-Python bugfix release
(mvnmle/mice carry no Cython); the compiled timeseries/survival kernels are
unchanged from 6.0.0.

## The 12 fixes (all with regression tests)

mice: pool riv/λ consistency + zero-within-variance warning; constant-numeric-column
warning; polyreg/polr fall back (not crash) on unfittable categorical; logreg genuine
penalty toward marginal-rate intercept (no separation collapse); GPU categorical NaN
sentinel propagation (fail-loud, no silent collapse); accept constant fully-observed
categorical predictor.
mvnmle: eps noise-floor constant guard (no false reject of large-offset varying cols);
reference-solver NaN loglik + not-converged on failure sentinel; GPU fp32 collinearity
screen on raw sample cov, PD-guarded (no silent-wrong, no incomplete-data false
positive); honest SCALING diagnosis; documented exception type on extreme collinearity.

## Two process lessons (for the record)

- mice `logreg`'s "ridge" was in the Hessian only, absent from the gradient → at
  convergence it solved the UNPENALISED score equation and diverged under
  separation. A ridge that isn't in the gradient isn't a penalty.
- The first #03 gate attempt false-positived: screening collinearity on the raw
  pairwise covariance refuses fittable incomplete-data problems (pairwise deletion
  is EXPECTED to be non-PD). Only screen when the raw cov is PD. Caught solely by
  re-running the R12/R13 gate — always re-prove a gate after touching it.
