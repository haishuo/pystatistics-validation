# Archived — original sanity-check suite (pre-architecture)

This directory preserves the **original** `pystatistics-validation` suite as it
existed before the repo was redesigned (2026-06-25) into the canonical home for
version-pinned validation evidence and reports. See `../ARCHITECTURE.md` for the
design that replaced it.

**Status: inert.** Nothing here runs as part of the new architecture. It is kept
for one reason: the **R reference values and the Python↔R comparison logic are
salvageable** and will seed the second-wave reports (LM, GLM, ANOVA, PCA, survival,
descriptive, …) once the mvnmle + mice vertical slice is proven end-to-end. The
**pytest wiring itself is disposable** — it installed pystatistics/pystatsbio from a
*local editable checkout* (violating the PyPI-only principle) and persisted nothing
but R references.

## What's here

- `suite1_pystatistics/` — pystatistics vs R: OLS/`lm`, GLM (binomial/poisson/gamma/
  negbin), descriptive, hypothesis, ANOVA, mixed/LMM, survival (KM/log-rank/coxph),
  categorical+interaction terms, ordinal (`polr`), multinomial, multivariate
  (PCA/factor analysis), timeseries, GAM, bootstrap. R refs in
  `fixtures/r_results.json` + `fixtures/newmodules/r_results.json` (generated by the
  `run_r_*.R` scripts).
- `suite2_pystatsbio/` — pystatsbio vs R: power, dose-response (LL.4), ROC/AUC/DeLong,
  PK NCA, epidemiology, meta-analysis, GEE.
- `suite3_gpu_stress/` — CPU↔GPU correctness/stability/speed on TCGA BRCA + synthetic.
- `data/` — datasets + R reference JSON (pbc, NHANES-derived pystatsbio_r, tox21) and
  the dataset download script.
- `conftest.py`, `setup_env.sh` — old root test config + (local-source) env setup.

## Salvage guidance for second-wave reports

When rebuilding a subsystem report under the new architecture, mine the matching
old test for: (a) the canonical real R dataset it used and *why* (the WHAT/HOW/
DATASET/WHY rows in the old README, reproduced in git history), (b) the exact R
reference values, and (c) the per-claim tolerances. Re-emit those as frozen
artifacts produced against a **PyPI-installed** pystatistics, then render.
