# A7 torch-free certification — pystatistics v5.0.0

> Certifies that the entire **pystatistics v5.0.0** corpus (installed from **PyPI**) runs **correctly without torch**, and that every explicit `backend='gpu'` entry point **fails loud** when no GPU/torch is present. Evidence lives in `artifacts/a7_torchfree/v5.0.0/`. Generated by `render_report.py` from frozen artifacts — **do not edit numbers by hand**; fix the artifact or the renderer and re-render.

**What A7 requires** (CONVENTIONS.md A7 + A6, RIGOR foundational Guarantee 2): numpy + scipy are the only hard runtime dependencies; **torch is an optional `[gpu]` extra**. The package must run correctly torch-free — degradation is *performance only*, never function or correctness — and an explicit GPU request without a usable GPU/torch must be **disclosed and fail loud**, never silently served on the CPU.

### Finding A7-1 — `arima` / `auto_arima` GPU silent-CPU, fixed at 4.6.12

An earlier certification pass surfaced one real fidelity defect. Before 4.6.12, `arima(..., backend='gpu')` and `auto_arima(..., backend='gpu')` **silently computed on the CPU** and reported `backend_name='cpu'`: their exact-ML/CSS-ML/CSS path has no GPU kernel, and the `backend=` argument was ignored rather than validated — a silent backend substitution (Guarantee-2 / A6 violation). At v4.6.11 this driver recorded `timeseries.arima[gpu]` as **not loud**.

The fix makes both functions raise on an explicit GPU backend (`gpu`/`gpu_fp64`/`mps`/`cuda`) for any method other than `'Whittle'` — the one ARIMA method that *does* have a GPU implementation — pointing the user to the real GPU paths (`method='Whittle'` with `backend='gpu'`, or `arima_batch`) or to `backend='cpu'`. The `Whittle` GPU path and `arima_batch` are unchanged; `backend='cpu'`/`None`/`'auto'` fits are byte-for-byte unchanged (§2).

At 5.0.0 both now fail loud:

- `timeseries.arima[gpu]` → `ValidationError`: arima()'s exact-ML/CSS path has no GPU backend (backend='gpu', method='css-ml'). Use method='whittle' with backend='gpu' for the frequency-domain GPU path, arim
- `timeseries.auto_arima[gpu]` → `ValidationError`: arima()'s exact-ML/CSS path has no GPU backend (backend='gpu', method='css-ml'). Use method='whittle' with backend='gpu' for the frequency-domain GPU path, arim
